# Yiddish style for all `yi` text (used by p4-extract.md, p4b-writeup.md and audit.md)

Readers are Chassidish Yiddish speakers who read *Der Yid*, *Der Blatt* and *Di Tzeitung*. Write the way those papers write about a shiur: natural spoken-Chassidish Yiddish in their spelling, with loshon-hakodesh words spelled as in a sefer. The pilot judges flagged three recurring faults: **YIVO spelling**, **Daytshmerish** (German words and forms), and **English calques**. Avoid all three.

## 1. Orthography: Chassidish, never YIVO

No nikud and no YIVO diacritics or ligatures, ever. Plain letters only.

| Don't (YIVO / klal-shprakh) | Do (Chassidish) |
|---|---|
| `וווּ`, `װוּ` | `וואו` |
| `אַ`, `אָ` (pasekh/kamets alef) | `א` (`א משל`, `אזוי`, `האט`) |
| `פֿון`, `פֿאַר`, `פּסוק` | `פון`, `פאר`, `פסוק` |
| `װ`, `ױ`, `ײ`, `ײַ` (ligatures) | `וו`, `וי`, `יי`, `יי` (`וועלט`, `אויך`, `זיין`, `מיין`) |
| `ניט` | `נישט` |
| `ייִדן`, `ייִדיש`, `ייִד` | `אידן`, `אידיש`, `א איד` |
| `שאַבעס`, `יאָנטעוו`, `צאַדיק`, `תּפֿילה` | `שבת`, `יום טוב`, `צדיק`, `תפילה` |
| `מעשׂה`, `שׂמחה` (dotted shin/sin) | `מעשה`, `שמחה` |

Contractions with an apostrophe as the papers write them: `ס'איז`, `מ'זאגט`, `ס'שטייט`, `ער האט'ס`. Common forms: `נישט`, `וואס`, `איז`, `אזוי`, `פארוואס`, `ווייל`, `ווען`, `וויאזוי` / `ווי אזוי`, `עפעס`, `אלעמאל`, `דערנאך`, `דאס הייסט`, `אפילו`, `ממילא`, `דהיינו`.

Loshon-hakodesh words keep their sefer spelling: `שבת`, `אמונה`, `תפילה`, `צדיק`, `רשע`, `תשובה`, `רבונו של עולם`, `נפש השנית`, `נפש האלקית`, `חז"ל`, `רש"י`, `הקב"ה`, `השם יתברך`, `גמרא`, `מדרש`, `זוהר`, `פסוק`, `בית המקדש`. Abbreviations with `"` (gershayim): `חז"ל`, `רש"י`, `ע"ה`, `ב"ה`.

## 2. Vocabulary: Chassidish, not Daytshmerish

Where a German-flavored word has a normal Yiddish or loshon-hakodesh word, use that.

| Don't (Daytshmerish) | Do |
|---|---|
| `דער ספר וועלכער ...`, `די זאך וועלכע ...` (relative "welcher") | `דער ספר וואס ...`, `די זאך וואס ...` |
| `עטוואס` | `עפעס` |
| `ווירקליך` | `טאקע`, `באמת` |
| `בעזאנדערס` | `בפרט`, `ספעציעל` |
| `פאלגליך`, `דעמנאך` | `ממילא`, `דערפאר`, `לפי זה` |
| `אויפגאבע` | `תפקיד`, `עבודה` |
| `ציל` | `תכלית` |
| `באדייטונג` | `טייטש`, `פשט`, `באדייט` |
| `ערשיינונג`, `געשטאלט` | `זאך`, `ענין` |
| `זיך באפינדן` | `זיין`, `זיך געפינען` |
| `פארשטענדליך` | `פארשטייט זיך`, `מובן` |
| `דאדורך` | `דורך דעם` |
| `נאטירליך` (as filler) | `פארשטייט זיך`, or leave it out |

Learning vocabulary is welcome and natural: `ער פרעגט א קשיא`, `דער תירוץ איז`, `ער ברענגט א ראיה פון`, `דער חילוק איז`, `ער איז מסביר`, `ער איז מחדש`, `דאס איז מתורץ`, `על פי זה`, `דאס איז דער פשט`, `דער משגיח לייגט צו`.

## 3. Syntax: Yiddish sentences, not English ones in Yiddish words

| Don't (English calque) | Do |
|---|---|
| `עס נעמט פלאץ` ("takes place") | `עס קומט פאר`, `עס איז געשען` |
| `דאס מאכט זינען` ("makes sense") | `דאס איז מסתבר`, `מ'פארשטייט עס` |
| `אין סדר צו` ("in order to") | `כדי צו`, `אז מ'זאל` |
| `ער פוינט אויס` ("points out") | `ער ווייזט אן`, `ער מערקט אן` |
| `אויף די אנדערע האנט` ("on the other hand") | `לאידך גיסא`, `פון דער אנדערער זייט` |
| `דאס איז וואו ...` ("this is where") | `דא ...`, `דערמיט ...` |
| `ער ברענגט ארויף א פונקט` ("brings up a point") | `ער ברענגט א נקודה`, `ער מאכט אויפמערקזאם` |
| `עס איז וויכטיג צו באמערקן אז ...` | (filler; leave it out) |
| `רעקארדינג`, `סעקשן`, `פאינט` (English words) | `שיעור`, `חלק`, `נקודה`; `צווייטע טייל פונעם שיעור` |
| `ער פרעגט די קשיא: וואס איז ...?` with English word order | `ער פרעגט: פארוואס זשע ...?`, `ער פרעגט א קשיא, אז ...` |

The verb goes in second position (`דערנאך ברענגט ער...`, not `דערנאך ער ברענגט...`). Use `אז` freely to introduce reported speech (`ער זאגט אז ...`). Short, connected sentences, as a reporter of a shiur writes them; not one long sentence translated from English.

## 4. Self-check

Before writing a `yi` field, reread it once and ask: would a Chassidish reader of *Der Yid* write it this way? Any nikud, dotted or ligature letter, `ניט`, `וועלכע(ר)` as "which", `עטוואס`, an English word in Hebrew letters, or an English idiom carried over means: rewrite the sentence.
